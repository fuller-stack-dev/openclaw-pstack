## interrogate

New native and agent-led ledger admissions freeze executedProof: true. Records lacking that selector keep the preserved legacy rubric, contracts, profiles and replay. Corrections inherit their source selector and proof inputs. There are still two reviewers and the existing native lead:0, with no new role or workflow kind.

1. Record intent, reproduction-policy and frozen-head. frozen-head is JSON matching the frozen schema: exact Git revision and tree, SHA256 of the reviewed patch (including an empty patch), and literal repo-relative scoped files with SHA256. Keep complete immutable patch and repro inputs available. A reported command is not authorized merely because it was reported.
2. Give both reviewers identical frozen inputs. Each uses ordinary agent exec in its own disposable scratch rebuilt from the frozen tree and patch. Inspect commands and every repro file first. Verify hashes before and after. Return observed failures with command, absolute scratch/cwd, nonsecret environment, execution outcome (observed, harness-failed, unsafe or unavailable), exit and expected exit, actual and expected, hash-pinned repro files and safety rationale. Empty findings are valid; record tested coverage. Missing execution or unsafe repro is BLOCKED.
3. Collect both reviewers before the independent lead. Give the lead exact structured outputs and artifact digests. The lead inspects commands and repro bytes independently, then reconstructs FRESH scratch from frozen inputs, not reviewer scratch. Verify source and repro hashes, retaining both frozen and frozenAfter. A BLOCKED lead can retain complete typed per-origin accounting, but cannot complete the workflow. Run every finding independently. Account for each origin as keep, drop, blocked or an exact duplicate of a directly rerun origin. A failed harness, source drift, unsafe command, missing reviewer or unavailable rerun is BLOCKED, not a drop or PASS.
4. Deliver Intent / Findings / Dropped with reviewer/model attribution, command / actual / expected and per-origin reasons. Findings contains independently reproduced failures; Dropped contains refutations and duplicate mappings. Empty healthy review is PASS. Assurance is agent-attested and independently rerun, NEVER host-verified execution. The controller validates and records typed evidence only.
5. Agent-led v1 uses the same reviewer contract and final independent-lead checkpoint. Resolve judgment and prose and spawn/collect an independent lead through ordinary native tools; do not self-judge. The gate is JSON {status, output} using the executed lead contract. Check tools need frozen context and both collected reviewer outputs/digests. Native v2 owns lead:0 itself.

Bounded contracts refuse overflow instead of truncating proof fields. Scope or split oversized reviews before admission. Preserve custody and cancel a blocked full record. No automatic repair, publication, installation, or live service access.
