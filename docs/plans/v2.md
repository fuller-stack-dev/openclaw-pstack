# Pstack v2 capability contract

This public note carries only the shared capability contract from the historical
v2 plan. The rest of that plan is not part of this public checkout and is not
restored here as current rollout guidance.

## Shared contract

- Every addition is an optional field or method, versioned by a string token
  checked with `api.runtime.capabilities?.includes("<capability>-v1")`, such as
  `command-native-subagents-v1` or `requester-model-catalog-v1`. Do not attach
  capability properties to the string array.
- If the token is absent, the plugin treats it as unsupported and omits the
  corresponding `runtimeCapabilities` registration opt-in.
- Each capability is bound to the plugin, the current requester’s authority,
  the exact parent session incarnation and native tool policy. That binding is
  rechecked after every await.
- No capability adds caller-selected identities or admin fallbacks.
